# Blaze Game Developer Portfolio

A dark, game-focused portfolio website for Pratik Meshram.

## Files

- `index.html` — page content
- `style.css` — visual design and responsive layout
- `script.js` — reveal animations and cursor effect
- `assets/images/` — add project screenshots here
- `assets/videos/` — optional local videos
- `assets/resume.pdf` — add your resume here

## Before publishing

Replace these placeholders in `index.html`:

- `YOUR_EMAIL@example.com`
- `YOUR_GITHUB`
- `YOUR_LINKEDIN`
- YouTube URL
- `assets/resume.pdf`

Then replace the generated project visuals with your real screenshots/GIFs/videos when ready.

## GitHub Pages

1. Create a public repository named `YOURUSERNAME.github.io`.
2. Upload the files in this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.
7. Your site will appear at `https://YOURUSERNAME.github.io`.

No server or paid hosting is required.

## Skills icons
The skills section uses locally rendered text/icon tiles rather than third-party logo files. This keeps the GitHub Pages site self-contained and avoids implying endorsement by tool vendors.
