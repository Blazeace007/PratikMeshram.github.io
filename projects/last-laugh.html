WHAT IT IS

A darkly playful platformer.

Last Laugh is a 2D platformer prototype built around a stylized horror-comedy identity. The project combines platforming movement with close-range weapon combat and a deliberately strange visual tone.

The prototype was also used to explore animation, combat, UI and environmental presentation while iterating quickly in Unity.

MY WORK

Systems & implementation

Animation — Created and implemented character animations while developing the project.

Weapon Combat — Implemented a scissor-based weapon and new attack animations.

Movement — Added run, jump, double jump, dash, pogo attack and wall climb mechanics.

Defense — Added a guard mechanic alongside the movement and combat toolkit.

UI — Reworked the main menu UI to fit the game's visual direction.

World — Built the world environment, backgrounds and gameplay objects.

SYSTEM BREAKDOWN

Core gameplay.

01

Platforming Toolkit

Run, jump and double jump form the base movement, with dash and wall climb adding more ways to navigate the environment.

02

Scissor Combat

The combat identity is built around a scissor-based weapon, supported by custom attack animations and close-range interaction.

03

Advanced Movement

Pogo attacks and wall climbing expand the platforming vocabulary and create opportunities for movement-driven encounters.

04

Guard & Presentation

A guard mechanic adds defensive play while the reworked menu, backgrounds and world objects reinforce the project's dark, playful tone.

DESIGN DIRECTION

Dark humor. Playful danger.

The project deliberately contrasts cute, exaggerated character art with dangerous platforming and combat. That contrast became part of the game's identity: visually playful on the surface, but built around hazards, attacks and fast movement.
